# Pilates Physics Marketing Reference

This folder is the source of truth for who Pilates Physics is for and how it
talks. Read it before writing any marketing page, email, landing section, social
hook, or ad. The goal is that every piece of copy sounds like the same brand and
speaks to a real person, grounded in what actual students told us.

## How to use this when writing copy

1. **Start with the audience.** Open [icp-profiles.md](icp-profiles.md) and pick
   which ICP the piece is for. Default to **ICP 1 (The Curious Practitioner)**
   unless there is a reason to target ICP 2 or 3.
2. **Grab the message.** Open [peace-framework.md](peace-framework.md) for the
   ready-made Problem, Empathy, Answer, Change, and End Result soundbites. These
   drop straight into heros, subject lines, and hooks.
3. **Pull real language.** Open [customer-language.md](customer-language.md) for a
   swipe file of real student quotes grouped by theme. Reuse their words.
4. **Check the voice.** Run the draft against
   [voice-and-messaging.md](voice-and-messaging.md) before you ship it. That file
   is the final word on tone and copy conventions.
5. **Lay out the page.** For the section order of a landing or marketing page
   (hero, stakes, value, guide, plan, footer) and an audit checklist, use
   [website-structure.md](website-structure.md).
6. **Match the visuals.** For layout, type, color, and components, use the
   visual companion, [../design-system.md](../design-system.md).

## Source of truth notes

- **Copy conventions live here, not in the design system.** Where
  [voice-and-messaging.md](voice-and-messaging.md) and
  [../design-system.md](../design-system.md) disagree on how copy should read
  (for example, em dashes), the voice guide wins.
- **The audience insight is real, not invented.** The ICPs and quotes come from
  22 post-workshop survey responses (Pilates Physics 101 and 102). See the data
  basis and its one caveat at the bottom of [icp-profiles.md](icp-profiles.md).
